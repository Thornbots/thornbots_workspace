Validation

Page sizes and sources match.
Every saved edition was reopened and each page size compared with its source; all source MD5 hashes still match the translation index.
All 612 contents links resolve.
Source rows were counted independently from extracted text, then each internal link was checked for source page, destination page, valid range and English destination heading or caption. This includes the already-English RM Award entry.
No untranslated text remains.
No untranslated source text regions and no extractable Chinese text remain in the English editions. Original branded artwork is retained.
Visual review found and fixed layout defects.
Contact sheets covered all 387 pages; crowded tables, figure keys, covers, pyramids and flowcharts were inspected at full size. Fixed: overlapping flowchart paragraphs and diagram legends, missing cells from incomplete source table borders, and cover fragments.
Navigation has regression tests; checks pass.
Tests cover English-only contents rows, digits at title starts (Figure 3-1 versus 3-13, 3V3), printed page numbers that include the cover, unchanged source bytes and atomic PDF publication. Workspace quality checks and actionlint pass, as did the document relocation in all nine affected package repositories. Link checks found only existing unavailable targets in the optional, uninitialized firmware/MCBV3 submodule.

Layout limits

English text is fitted into the source regions, with smaller fonts where needed. Font metrics and line wrapping can differ from the Chinese edition; physical pages, source artwork positions, table borders and content page breaks stay fixed. The two talent-development pyramids use English vector artwork within the source figure boxes.
