Decision and frame contract

RELOCALIZE carries the AMCL-corrected absolute field position.
The local EKF pose alone cannot correct global drift. Firmware already treats x/y as absolute and replaces a translation-only navigation offset, so the UART payload and board behaviour are unchanged.
The adapter composes the correction at backend capture time.
It pairs backend map->root with interpolated nav_odom->root at the backend stamp and composes the planar correction with each current EKF input. This avoids AMCL's future-dated TF and removes the unbounded latest-TF fallback. The relay rotates raw displacement by the correction yaw; neither raw aim odometry nor nav_odom->odom gets a yaw correction.
Blank mapping has no absolute source.
Mapping, blank-map SLAM and none keep team-start navigation. Waypoint arrival reads the relay's nominal held-position estimate. UART has no acknowledgement, so temporary disagreement after a lost fix is possible until a fresh retry; the estimate is not actual navigation feedback.
Missing history or expired covariance yields an invalid result, not a wait.
NaN position and infinite covariance at that input stamp make the relay emit a none-mark and release the lockstep chain. AMCL particle/callback timing stays nondeterministic.

Contracts: localization, relay, arrival, UART.

Measurement method

A both-team moving case runs Gazebo scans, the real rf2o/EKF/AMCL stack, the real UART bridge and compiled hosted sentry firmware: drop the first startup RELOCALIZE, then two 0.6 × 1.2 m loops at 0.4 m/s with 15% pod scale error and 0.025 m/s accumulating x bias.

  • Score is actual firmware odo.getX()/getY() read through the private hosted MappingStatus socket against current hardware truth (status is one 5 ms tick old, about 2 mm at 0.4 m/s). It includes gate holds, dropped frames and the single receive slot; it is not reconstructed from TF or the relay.
  • The delivered-target-vs-firmware metric includes observation lag and does not prove every target survived the firmware mailbox.
  • Before runs use unmodified nightly runtime sources plus the same readout fixture, rebuilt from baseline gitlinks in an isolated overlay. Three trusted runs per team before and after; native log-check failures invalidate a case. The supplied startup archive has no held-position metric and is not used to invent moving before values.

Findings during implementation

AMCL's stationary prior can report covariance near −1e-12 m².
A 1e-9 roundoff tolerance accepts it; materially negative or nonfinite covariance is still rejected.
Exact TF lookup at the input stamp cannot bootstrap.
The first transform is future-dated by transform_tolerance; same-stamp composition removes the dependency.
A parked AMCL backend publishes nothing unless asked.
In a red startup diagnostic only 12 inputs (about 0.37 s) were usable before covariance expired; the first fix was dropped with no retry. No-motion scan requests restore a fresh source instead of extending the lifetime. The replacement run missed the initial publication (backend=0 throughout); localization a57f186 extends refresh to a missing backend, with an installed-node test.
The firmware's shared receive mailbox is a nonstandard loss point.
A successful Jetson publish is not proof of application, so the metric reads actual firmware state.
A wrong AMCL basin was accepted despite small covariance.
replacement-2: held-position RMS/p95/max 8.841/9.856/9.990 m. Relay 2aace64 adds the referee-start prior and a regression with that wrong position. No automatic global reset is added; persistent basin failure needs source recovery or operator intervention.
The existing EKF fixture was wrong before and after this work.
Truth booted at the loop centre while navigation used the blue start, and raw-zero POSE was compared with absolute truth (4.251 m fused mean error). The repaired fixture uses its known spawn for seeding and raw translation.
Some exploratory runs were excluded.
An occasional PING round-trip over the 100 ms gate and Gazebo teardown needing SIGTERM/SIGKILL; gates and baselines were not relaxed and affected cases are retained but excluded from trusted accuracy.
